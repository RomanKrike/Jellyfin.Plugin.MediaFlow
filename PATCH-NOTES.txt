MediaFlow v0.1.25

Anime filename parsing, actionable HTTP errors and stable dashboard refresh.

Changes:
- Recognizes TV-1 03/05, TV 1 05 and TV-2 12 anime episode names.
- Supports [SubsPlease]/[EMBER] names with spaced - 05 and episode revisions.
- Uses shared episode markers for title cleanup and season/episode extraction.
- Accepts bare trailing episode numbers only with known season context.
- Preserves dotted titles and numeric series titles such as 1923.
- Uses the same parser for imports, sequential priorities and legacy review recovery.
- Displays backend HTTP messages instead of [object Response].
- Keeps TMDb titles, seasons, loaded posters and expanded file panels while polling.
- Refreshes cached metadata without resetting cards to torrent names.
- Deduplicates detail requests and ignores obsolete overview/detail responses.
- Keeps the last display after a failed request; successful responses can update or clear it.
- Adds 86 parser regression checks and six admin UI tests.
- Runs regression checks before the release build can publish.

Absolute anime episode numbers are not mapped to different TMDb seasons.
Ambiguous episode ranges are not treated as a single anime episode.

After updating, restart Jellyfin and reload the MediaFlow page with Ctrl+F5.
Use Retry analysis / Reprocess for anime files previously waiting for review.
