MediaFlow v0.1.12 release recovery fix

The plugin build and v0.1.12 GitHub Release already succeed.
The failing part is the final manifest publication step.

This patch:
- keeps version 0.1.12;
- reuses an existing v0.1.12 tag and GitHub Release;
- replaces the final runner-side git branch/commit/push with GitHub Contents API;
- reads the latest manifest.json from main before updating it;
- retries up to 3 times if main changes concurrently;
- is idempotent if 0.1.12.0 is already present.

After pushing this workflow patch, the next run should rebuild 0.1.12,
refresh its release asset, and repair manifest.json.
